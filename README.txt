RED E CORP. WEBSITE — UPLOAD NOTES

UPLOADING
Upload everything in this folder (index.html + the assets folder) to your
host's web root — usually "public_html" or "www". Keep the folder structure
exactly as it is.

BEFORE GOING LIVE
1. Projects section: replace every [bracketed] placeholder in index.html
   with real project names, locations and descriptions.
2. Add photos (JPG, roughly 2000px wide, desaturated / cool-toned per the
   brand system) into assets/img/ with these exact names:
     hero.jpg        structural steel / jobsite at dusk (wide)
     founder.jpg     John on site, unposed
     project-1.jpg   \
     project-2.jpg    > one per project card
     project-3.jpg   /
   Until a photo is added, that spot shows as a plain charcoal panel.
